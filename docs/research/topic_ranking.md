# Topic ranking

Generated by `python3 -m discovery.rank --write` from `discovery/data/topics.json`. Edit the JSON, not this file.

Score = 0.30 × trend_strength + 0.25 × visual_potential + 0.20 × originality + 0.15 × rendering_feasibility + 0.10 × novelty, each term 0–100.

Trend, visual, originality and feasibility are human estimates made on 2026-10-31 without YouTube API data. Novelty is computed: it drops when other topics on the slate share the scenario family or a named institution. Replace trend estimates with measured competitor view velocity once `discovery.competitors observe` has run twice.
