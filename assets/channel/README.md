# YouTube pixel identity

The current nameless channel identity is an ivory pixel question mark with a red
square dot and three orbiting blue/green Earths. The banner connects it to a
campus and an imagined future city. These are channel artwork files, independent
of the production website's engine name.

- `whatif-profile-800.png`: 800 × 800 opaque upload PNG, checked with a circular
  crop and at 98-pixel display size.
- `whatif-banner-2560x1440.png`: 2560 × 1440 opaque upload PNG; the central emblem
  and both worlds fit in a conservative centered 1544 × 422 mobile crop.

Artwork was created with built-in ImageGen, then exported on a consistent pixel
grid with a shared 16-color palette and nearest-neighbor scaling. The avatar uses
an 80 × 80 logical grid; the banner uses 320 × 180. See `prompts.md` for the final
image prompts. The selected native masters and export script remain in the local
`output/branding/whatif-pixel-v1/` working pack.

Upload and review crops in YouTube Studio → Customization → Profile. Nothing was
published automatically. Dimensions and crop checks use
[YouTube's official guidance](https://support.google.com/youtube/answer/10456525?hl=en).
